# Escape the volcano

This is my first rage game that i make easier after i get enraged so its just a game not

The concept is simple you are inside a volcano thats about to erupt and lava rises after a fixed amount of time and you have to escape it (beware of spikes)

![img](/images/mainMenu.png)

## Controls

- a/d or ←/→ to move
- Space/w/↑ to Jump
- Shift/Control to sprint
